# Agent Guide

CareShare is an iPhone-first iOS app for coordinating non-clinical support during the first 72 hours after hospital discharge. The iPad demo uses the same app build and iPhone layout.

Read these files before making changes:
- [README.md](README.md): product purpose, users, and task-sharing concept.
- [HackathonNotes.md](HackathonNotes.md): mission-critical challenge requirements, demo constraints, and judging criteria.
- [DESIGN.md](DESIGN.md): proposed screens, task states, visual direction, mock payment flow, implementation outline, and acceptance criteria. Distinguishes confirmed requirements from proposals.

Keep the core caregiver journey under ten minutes. Payments and provider bookings are simulated for the demo; do not collect real payment details. Use fictional demo data. Preserve the single-build iPhone/iPad demo decision unless the user changes it.
